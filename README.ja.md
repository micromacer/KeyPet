## 概要

KeyPetはデスクトップペットアプリです。ルールに沿ってPNG/APNGのキャラクター素材を用意すれば、キーボードを叩いたときにペットが対応するリアクションを取り、上方向に弾むように揺らすこともできます。

このデスクトップペットアプリはAppleシリコン搭載のMac専用に開発され、Swift 6で構築され、レンダリングとタイミングの基盤としてCore Animationを採用しています。アーキテクチャはパフォーマンスの最適化を最優先に設計されているため、他のクロスプラットフォームのデスクトップペットプロジェクトと比べて、より少ないリソース消費で同様に滑らかな60 FPSのアニメーションを実現できます。

KeyPetは豊富なアニメーショントリガーに対応しており、叩いたキーのキーボード上の位置（左側/右側）に応じてトリガーできるほか、特定のキーに専用の動作画像を設定することもできます。

さらに、キャラクターの左右反転、左右の手足の反応の入れ替え、リアルタイムの影の追加が可能で、サイズ、不透明度、手足のアニメーションが元に戻るまでの時間も調整できます。

**⚠️注意：** **KeyPetにはペット素材は付属しません。**ご自身でデザイン・制作するか、正規のルートからペット素材をダウンロードしてください。

## 動作環境

- Appleシリコン（arm64）搭載のMac、macOS 15.0以降。

Intel搭載のMacには対応していません。

## インストール

1. **Releases**ページの**Assets**から、最新バージョンの`.dmg`インストールイメージをダウンロードします。
2. `.dmg`イメージをダブルクリックし、**KeyPet.app**を**アプリケーション（Applications）**フォルダにドラッグします。

## 初回起動

案内に従って、**システム設定 → プライバシーとセキュリティ → 入力監視**で**KeyPet**を有効にしてください。リストにKeyPetがない場合は、リストの下にある「+」ボタンをクリックして追加してください。

有効にした後、システムの指示に従ってKeyPetを開き直し、ペット素材を保存しているフォルダを選択してください。この設定は後からメニューで変更できます。

## 「入力監視」について

KeyPetは前面でキーボードフォーカスを占有しないため、キーボード入力を感知する唯一の方法は、macOSのCore Graphics APIを通じてキーボードイベントをグローバルに監視することです。そのため、「入力監視」へのアクセス許可が必要となります。

ご安心ください。**KeyPetにはネットワーク通信、分析、テレメトリの機能は一切なく、キーボード入力の情報を保存・送信することもありません。**ソースコードからいつでもこの事実をご確認いただけます。

## ペット素材の準備

### 基本条件

- 静止画PNG（`.png`）またはアニメーションPNG（`.apng`）形式の画像ファイル
- 画像の幅と高さはいずれも2048 px以内
- 1ファイルのサイズは64 MiB以内
- アニメーションファイルの最大フレーム数は2000フレーム

### フォルダ構成

KeyPetは素材ルートフォルダ内のサブフォルダでペットを区別します。具体的な構成は以下のファイルツリーを参照してください：

```text
MyPets/
└── Swordsman43/
    ├── pet-idle.png
    ├── pet-left.png
    ├── pet-right.png
    └── pet-space.png
```

サブフォルダの名前はペットの名前として扱われ、メニューに表示されます。ここでは`Swordsman43`が該当します。

### ファイル名の命名規則

#### 基本情報

1つのファイルが1種類のキャラクターの動作として扱われ、ファイル名によって、どのキーが押されたときにその動作がトリガーされるかが決まります。

ファイル名の形式は次のとおりです：

```text
pet-<token>.png  または  pet-<token>.apng
```

このうち`pet-idle`は待機時に表示されるキャラクターで、**必ず存在している必要があります。**`pet-left`と`pet-right`は左右の手足の動作で、キーボードの左右の手の担当、または左/右の矢印キー`←/→`、音量の小/大キー、前の曲/次の曲キーによってトリガーされます。

**1つのペットには、少なくとも`pet-idle`、`pet-left`、`pet-right`を含めることをおすすめします。**

#### 動作のマッチングルール

キーが押されるたびに、KeyPetは次の順序で動作を選択します：

1. **キー専用のtoken**：`1`、`a`、`space`、`enter`など。
2. **左右の手足**：専用画像のないキーは、左右の担当に応じて`left`または`right`をトリガーします。
3. **待機画像**：`left`や`right`に関する素材がない場合は、`idle`が表示されます。

#### 素材の読み込み

起動時に、KeyPetは素材ルートフォルダ内のすべてのサブフォルダを読み込みます。また、KeyPetは素材の変更を自動的に認識して再読み込みするため、素材の差し替えや追加・削除後にアプリを再起動する必要はありません。

ペットが正常に認識されない場合は、メニューから**ペット - 再スキャン**を選択してください。

#### サンプルペット

サンプルペットの素材ファイルは[こちら](demo)からダウンロードできます。

## ソースからビルド

Xcode 26以降（Swift 6とIcon Composerのサポートを含む）をインストールし、現在使用する開発ツールのディレクトリとして設定してください。ReleaseビルドはXcode 27.0で検証済みです。

```sh
xcodebuild -project KeyPet.xcodeproj -scheme KeyPet \
  -configuration Release -destination 'generic/platform=macOS' \
  -derivedDataPath build/DerivedData build
```

ビルド生成物は`build/DerivedData/Build/Products/Release/KeyPet.app`にあります。

## よくある質問

1. **インストール後、ダブルクリックで直接起動できない：** **システム設定 → プライバシーとセキュリティ**を下にスクロールし、**このまま開く**ボタンをクリックしてください。
2. **インストール後にダブルクリックで起動すると、「壊れているため、開けません」と表示される：**まずKeyPetアプリのアイコンを右クリックし、メニューから**開く**を選択してみてください。それでも解決しない場合は、ターミナルで次のコマンドを実行してください： `sudo xattr -r -d com.apple.quarantine /Applications/KeyPet.app` 。
3. **キーボードのFnキーでキャラクターのアニメーションがトリガーされない：**一部の外付けキーボードでは、Fnキーの処理がすべてキーボード内部のファームウェアで行われ、macOSにキーイベントが送信されません。そのため、この種のFnキーはアプリで検出できません。ただし、システムのデフォルト設定では、Fn + ファンクションキーを押すことで、F1、F2などのファンクションキーに対応するアニメーションを正しくトリガーできます。
